# Sabi Studio 🎬

**You sabi the story. We make am move.**

Sabi Studio is an AI video studio built for African storytellers.
Type an idea, drop in an image, or record a voice note, and get back
a finished video with a music score, sound effects, and dialogue that
actually sounds like home: Hausa, Igbo, Yoruba, Nigerian Pidgin, Twi, Zulu, Swahili, and
more languages on the way.

Pick your style: anime, Disney-style animation, cinematic film, or
documentary. Pick your voices. Sabi Studio writes the scenes, speaks
the lines, scores the music, and puts it all together.

## Why Sabi Studio?

Most AI video tools can show you a beautiful picture, but they can't
talk like us. Sabi Studio puts authentic African languages and
accents at the center, not as an afterthought!

## Features

- Text, image, and voice-to-video
- Authentic African-accented speech (Hausa, Igbo, Yoruba, Pidgin, and more)
- Multiple visual styles: anime, Disney-style, cinematic, documentary
- Music, sound effects, and lip-sync
- Editable scenes: change the script, voices, and timing before you generate

## Status

🚧 Early development. Phase 1 (interface) is done; Phase 2 (script and
voice) is in progress.

## Tech stack

React, Tailwind, Supabase (Auth, Database, Storage, Edge Functions),
Claude API for scripting.
